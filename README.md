# Web Security Labs

Hands-on notes and selected exercises documenting my development in web application penetration testing.

This repository focuses on understanding vulnerabilities, identifying them methodically, validating their impact, and researching appropriate remediation.

## Current Learning Areas

- HTTP fundamentals
- Authentication
- Access control
- SQL injection
- Cross-site scripting (XSS)
- Path traversal
- File upload vulnerabilities
- Information disclosure

## Lab Documentation Format

For each topic I document:

- Concept
- Security impact
- Detection methodology
- Authorized lab practiced
- Evidence
- Remediation
- Lessons learned
- References
